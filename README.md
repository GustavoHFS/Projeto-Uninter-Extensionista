## Objetivo

Projeto acadêmico de extensão desenvolvido para apresentar uma proposta de apoio ao **descarte adequado de resíduos e à organização de pontos de coleta comunitários**. A interface busca estimular a conscientização e facilitar o entendimento de locais e tipos de resíduos.

## Funcionalidades demonstradas

- **Início:** apresentação da proposta e de seus objetivos.
- **Registrar ponto:** formulário visual com local, endereço e tipo de resíduo.
- **Pontos cadastrados:** lista de exemplos de coleta para ilustrar a navegação.
- **Navegação por seções:** alternância de telas implementada em JavaScript.

O projeto relaciona a proposta aos **Objetivos de Desenvolvimento Sustentável 6, 11 e 12**.

## Tecnologias

**HTML · CSS · JavaScript** — site estático, sem framework ou backend.

## Executar

Baixe ou clone o repositório e abra `index.html` em um navegador. O menu permite alternar entre as três seções.

~~~text
index.html   conteúdo, navegação e formulários
style.css    interface visual
script.js    alternância de seções
img/         ilustração temática
~~~

## Escopo atual

Trata-se de um **protótipo de apresentação**: o formulário não grava registros e a listagem de pontos está definida diretamente no HTML. Os locais exibidos não devem ser interpretados como cadastro atualizado ou serviço de coleta verificado.
